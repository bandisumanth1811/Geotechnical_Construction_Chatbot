# 🏗️ Geotechnical Construction Chatbot

> **An AI-powered Retrieval-Augmented Generation (RAG) assistant for Geotechnical & Civil Engineering.**

A domain-specific conversational AI that helps students, researchers, and engineering professionals quickly understand geotechnical engineering concepts, soil mechanics, foundation systems, drilling reports, and construction-related documentation using Large Language Models (LLMs) and Retrieval-Augmented Generation (RAG).

🌐 **Live Application:** https://geotechnicalchatbot.streamlit.app/

---

## 📖 Overview

Traditional large language models often struggle with highly specialized engineering knowledge and may generate inaccurate or incomplete responses. This project addresses that challenge by combining LLMs with Retrieval-Augmented Generation (RAG), enabling the chatbot to retrieve relevant engineering information before generating responses.

The chatbot is designed to support learning, research, and technical decision-making by providing context-aware answers based on domain-specific knowledge sources.

## 💻 Installation

Clone the repository

```bash
git clone https://github.com/bandisumanth1811/Geotechnical_Construction_Chatbot.git
```

Navigate into the project

```bash
cd Geotechnical_Construction_Chatbot
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
